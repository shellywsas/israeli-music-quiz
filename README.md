# 🎵 חידון המוזיקה הישראלית: זהה את השיר (Israeli Music Quiz)
### שומעים משפט ומנחשים מי הזמר ומה שם השיר! 🇮🇱✨

אתר משחק חדש ומרהיב במסך מלא (Full Screen) המוקדש לקלאסיקות ולהיטי הענק של המוזיקה הישראלית מכל הזמנים (משנות ה-70 ועד 2026). כולל פיצ'ר הקראה קולית חיה בעברית (Web Speech API), סינון לפי עשורים ומסך סיום חגיגי עם הכתרת מלכת המוזיקה!

---

## 🎶 מה מחכה בפנים?
* 🕰️ **שנות ה-70 וה-80:** כוורת ("המגפיים של ברוך", "יו יה"), אריק איינשטיין ("אני ואתה", "עטור מצחך"), שלמה ארצי ("ירח"), עפרה חזה ("חי"), צביקה פיק ("מרי לו").
* 🎸 **שנות ה-90:** משינה ("רכבת לילה לקהיר"), אתניקס ("תותים"), שרית חדד ("יאללה לך הביתה מוטי"), טיפקס ("איזה עולם"), אביב גפן, ברי סחרוף, דנה אינטרנשיונל ("דיווה").
* 💿 **שנות ה-2000:** עידן רייכל ("ממעמקים", "בואי"), עברי לידר ("בוא"), שירי מימון ("השקט שנשאר"), מירי מסיקה ("לשם"), הדג נחש ("שירת הסטיקר").
* 📱 **העשור האחרון והיום:** חנן בן ארי ("אלוף העולם", "אם תרצי"), נועה קירל ("יוניקורן"), פאר טסי ("דרך השלום", "רוקד עם הדמעות"), טונה ("סהרה"), עדן חסון, אודיה, נס וסטילה ("תיק קטן", "חרבו דרבו").

## 🎮 איך משחקים?
1. פותחים את [index.html](file:///C:/Users/shell/Documents/israeli-music-quiz/index.html) בכל דפדפן (או פותחים בקישור הישיר ב-GitHub Pages).
2. לוחצים על **"🔊 השמע את המשפט בקול רם!"** – המחשב יקריא את השורה בעברית!
3. שתיכן מנחשות בקול: **מה שם השיר ומי הזמר/ת המקורי/ת?**
4. לוחצים על **"חשוף את שם השיר והמבצע!"**.
5. מסמנים מי צדקה:
   * 👧 **שלי צדקה (+1)**
   * 👩 **אמא צדקה (+1)**
   * 👯‍♀️ **שתינו צדקנו! (+1 לכל אחת)**
   * ⏭️ **אף אחת לא ידעה**
6. בסיום 15 שירים עולה מסך הסיום החגיגי עם הכתר 👑 ומשימת שירה קורעת למפסידה!
